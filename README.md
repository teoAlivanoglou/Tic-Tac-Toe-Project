# Σε ένα τερματικό:

```bash
git clone https://github.com/teoAlivanoglou/Tic-Tac-Toe-Project.git
```

```bash
cd "Tic-Tac-Toe-Project"
```
```bash
pip install -r requirements.txt
```


* ## Για το κύριο πρόγραμμα:
    ```bash
    python src/main.py
    ```
    Σε windows αντί για `/` γράφουμε `\`:
    ```bash
    python src\main.py
    ```

* ## Για την προσομοίωση:
    ```bash
    python src/simulate.py
    ```
    *(Τα minimax χρειάζονται πολύ χρόνο για να τελειώσουν)*

* ## Ομοίως μπορεί κάποιος να τρέξει και μεμονωμένα τα υπόλοιπα αρχεία για να εκτελεστεί ο δοκιμαστικός κώδικας:
    ```bash
    python src/game.py
    ```
    ```bash
    python src/player.py
    ```
    ```bash
    python src/window.py
    ```


***ΣΗΜΕΙΩΣΗ:** (Σε κάθε περίπτωση μπορεί κάποιος να χρησιμοποιήσει το "pythonw" αντί για το "python" και να τρέξει το παράθυρο χωρίς μηνύματα στην κονσόλα.)*

# Εναλλακτικά:

* Τρέχουμε το [install-requirements-and-run.bat](install-requirements-and-run.bat) για να εγκαταστήσει όλες τις απαραίτητες βιβλιοθήκες και να τρέξει το πρόγραμμα.

* Τρέχουμε το [run.bat](run.bat) για να τρέξει το πρόγραμμα.

* Μπορείτε να κατεβάσετε και να τρέξετε το [έτοιμο .exe](https://github.com/teoAlivanoglou/Tic-Tac-Toe-Project/releases/latest).
